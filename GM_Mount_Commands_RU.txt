1. КАК ПОЛУЧИТЬ МАУНТА

Команды вводятся в игровой чат отдельными сообщениями.
Сначала включи доступ:
  /setpower

Получить маунта напрямую:
  /addrider ID_МАУНТА

Пример — Крылья Одина, Odin's Wings:
  /addrider 1206

Формат с одним ID взят из присланного руководства Menoz.
В локальной краткой памятке также упоминается второй параметр
«количество»: /addrider ID_МАУНТА 1. Как именно обработчик текущей сборки
разбирает этот дополнительный параметр, не проверено.
В примерах этого файла используется формат из руководства Menoz.

Другой способ — получить предмет и использовать его из инвентаря:
  /additem ID_ПРЕДМЕТА КОЛИЧЕСТВО

Пример предмета Крыльев Одина:
  /additem 62141 1

Скрипт предмета 62141 вызывает AddRider для ID 1206.
После использования предмета открой список маунтов и выбери его для езды.

ID маунта и предмета различаются:
  /addrider 1206   — ID из Rider.slk.
  /additem 62141 1 — ID из item.slk.

Обозначения ID_МАУНТА и ID_ПРЕДМЕТА заменяются числами.
Все примеры — отдельные варианты действий; вводить весь каталог не нужно.

3. УЛУЧШЕНИЕ МАУНТОВ

В Rider.slk у разных рангов одного маунта отдельные ID.
Поля UpgradeID и DegradeID связывают ступени улучшения.
Нулевой UpgradeID означает, что следующая ступень в этой записи не задана.

Пример цепочки Крыльев Одина:
  Rank 0: ID 1206; следующая ступень: 1207.
  Rank 1: ID 1207; следующая ступень: 1208.
  Rank 2: ID 1208; следующая ступень: 1209.
  Rank 3: ID 1209; следующая ступень: 1210.
  Rank 4: ID 1210; следующая ступень: 0.

Получить отдельного маунта сразу с Rank 4 по формату руководства:
  /addrider 1210

Это команда добавления маунта. Она не описана как улучшение уже имеющегося.

Для улучшения через игровую систему в Rider.slk указаны допустимые камни.
Основные предметы:
  60503 — Common Mount Gem.
  60504 — Elite Mount Gem.
  60505 — MP Mount Gem.

Пример выдачи 10 камней Elite Mount Gem:
  /additem 60504 10

У Крыльев Одина поле ItemID содержит 60504, 60491 и 60489.
Используй материал, указанный для конкретного маунта: типы камней различаются.
Выдача камней сама по себе не запускает улучшение.

Поля, относящиеся к улучшению:
  Rank            — ранг записи.
  Series          — серия маунта.
  UpgradeID       — ID следующей ступени.
  DegradeID        — ID предыдущей ступени.
  ItemID          — ID материалов улучшения, а не предмета получения маунта.
  ItemCount       — количество материала по таблице.
  StrengthenRate  — параметр вероятности улучшения.
  LuckyRate       — параметр удачи.
  LuckyAccumulate — параметр накопления удачи.

Формула вероятности и влияние удачи по одному файлу не подтверждены.
Значения StrengthenRate здесь не объявляются точными процентами.

4. СРОК, КЛАСС И УСЛОВИЯ ИСПОЛЬЗОВАНИЯ

Duration = 0 означает бессрочного маунта по заголовку Rider.slk.
Положительное Duration задано в минутах.

Два разных варианта Sleipnir:
  /additem 62156 1 — Rider ID 75, Duration 0, бессрочный.
  /additem 62146 1 — Rider ID 2004, Duration 43200, 30 дней.

Начало отсчёта и поведение таймера в офлайне здесь не проверены.

У отдельных маунтов есть ограничения класса и уровня.
Например, скрипт предмета Darkcharger 62002 требует уровень от 25
и код класса profession = 4. Сопоставление этого кода русскому названию класса
в этой памятке не устанавливается.

В полном каталоге Profession показан как исходный числовой код.
Даже при Profession = 0 условия использования предмета могут задаваться
его скриптом. Запись в каталоге не означает универсальную доступность
маунта для любого персонажа и карты.

5. СКОРОСТЬ, НАВЫКИ И ДРУГИЕ ПАРАМЕТРЫ

В Rider.slk есть ссылки на статусы Status / StatusLevel и навыки
Skill1–Skill3 / SkillLevel1–SkillLevel3. Характеристики конкретного маунта
нужно сверять с соответствующими таблицами статусов и навыков.

Проверенной отдельной GM-команды для установки скорости, качества или
ранга именно маунта в просмотренных материалах не найдено.
Команды /setpetgrowthrate, /setpetquality и /setpetlevel описывают питомцев;
к маунтам их применять как аналог не следует.

Ниже сохранены названия, ID, ранг, срок, серия, числовое поле MutiCount,
код Profession и ID следующей ступени.
MutiCount приведён как исходный параметр таблицы; доступность совместной
езды дополнительно зависит от реализации и условий игры.
Точное сравнение скорости маунтов этот каталог не содержит.
