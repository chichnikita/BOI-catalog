# BOI Catalog · Odin Atlas

Локальный визуальный каталог Battle of the Immortals, подготовленный по данным BOI Odin 4th Anniversary, версия сервера 5750.

В репозитории уже есть готовые данные и изображения. Для запуска достаточно Python; игра, виртуальная машина и исходные клиентские архивы не требуются.

## Возможности

- 49 213 записей в 28 категориях: предметы, экипировка, монстры, NPC, питомцы, маунты, карты, навыки и другие объекты.
- Отдельный справочник со 169 GM-командами и русскими пояснениями.
- Изображения для 31 895 записей; 5 060 уникальных игровых изображений.
- Описания 16 034 предметов из русского клиента и Boi-Memory, переключение источника описания.
- Поиск по ID, названию, описанию и характеристикам; фильтры, сортировка, режимы карточек и списка.
- Избранное в текущем браузере и копирование ID.
- Блок «Как получить / призвать»: GM-команды с подставленным ID, выбор количества и копирование.
- Связанные яйца, предметы маунтов, книги навыков и другие предметы активации, где связь найдена в файлах сервера.
- Загрузка собственных PNG, JPEG и WebP в карточку с сохранением на диске.
- Выгрузка таблиц ID и справочника команд.

Если полный формат GM-команды не установлен, это отмечено в карточке. Идентификаторы предметов, питомцев, маунтов и других таблиц относятся к разным областям; каталог учитывает это при подготовке команд. Сайт копирует команды для ввода в игровой чат. Исполнение на персонаже при подготовке справочника не проверялось.

## Быстрый запуск в Windows

1. Установи **Python 3.12 или новее** с [python.org](https://www.python.org/downloads/windows/).
2. Склонируй репозиторий или скачай **Code → Download ZIP** и распакуй архив.
3. Дважды нажми **Open-BOI-Catalog.cmd** в корне проекта.

При первом запуске создаётся окружение `.venv` и устанавливается Pillow из `requirements.txt`. Для этого требуется интернет. Затем каталог откроется в браузере:

**http://127.0.0.1:8765/**

Если порт занят другой программой, запуск проверит следующие порты до 8775. Повторный запуск откроет уже работающий каталог. Для остановки используй **Stop-BOI-Catalog.cmd**; закрытие вкладки не останавливает сервер.

Отдельная установка зависимостей из PowerShell:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Setup-BOI-Catalog.ps1
```

Запуск без открытия браузера, со своим портом или интерпретатором:

```powershell
.\Open-BOI-Catalog.ps1 -NoBrowser -Port 8765 -PythonPath "C:\Path\To\python.exe"
```

Можно также задать путь к интерпретатору через переменную `BOI_CATALOG_PYTHON`. В выбранном Python должен быть установлен Pillow.

## Ручной запуск

Подходит для Windows, Linux и macOS. Все команды выполняются из корня репозитория.

```bash
python -m venv .venv
```

Активируй окружение: в PowerShell — `.\.venv\Scripts\Activate.ps1`, в Linux/macOS — `source .venv/bin/activate`. Затем:

```bash
python -m pip install -r requirements.txt
python BOI-Catalog/server.py --port 8765
```

Сервер слушает только `127.0.0.1`. Завершение ручного запуска — `Ctrl+C` в терминале.

## Данные и локальные изменения

| Путь | Содержимое |
| --- | --- |
| `BOI-Catalog/server.py` | HTTP-сервер и API каталога |
| `BOI-Catalog/gm_actions.py` | Подготовка GM-команд с учётом типа ID |
| `BOI-Catalog/index.html`, `app.js`, `style.css` | Интерфейс без сборки |
| `BOI-Catalog/catalog.json` | Категории, записи и характеристики сервера |
| `BOI-Catalog/item-descriptions.json` | Описания предметов по ссылкам из клиентского `item.dat` и `item.string` |
| `BOI-Catalog/gm-item-links.json` | Связи предметов активации с игровыми объектами из серверных скриптов |
| `BOI-Catalog/assets/` | Готовые изображения и оформление |
| `ID_References/` | Выгрузки ID в CSV и TXT |
| `GM_*_RU.txt` | Русские справочники GM-команд |
| `BOI-Catalog/tools/` | Проверки API и интерфейса |

Пользовательские изображения и их привязки сохраняются в `BOI-Catalog/user-images/`. Журналы и сведения о запущенном процессе находятся в `_runtime/catalog/`. Эти папки исключены из Git. Избранное и выбранный язык описаний сохраняются в браузере.

Названия и характеристики получены из `GameServer/Slk` указанной сборки. Описания и изображения — из клиентов Battle of the Immortals. Текст клиента может отличаться от настроек сервера; параметры сборки показаны отдельно в карточке. Повторные ID с разными уровнями сохранены.

## Проверки

При работающем каталоге:

```bash
python BOI-Catalog/tools/check_api.py
```

Проверка API включает загрузку тестового изображения и восстановление исходной привязки.

Для проверок интерфейса нужен **Node.js 22+**. Установи зависимости для разработки и браузер:

```bash
npm ci
npx playwright install chromium
npm test
```

Проверяются поиск, фильтры, избранное, описания, команды, буфер обмена и мобильная вёрстка. Скриншоты сохраняются в `_runtime/catalog/`.

Тесты по умолчанию обращаются к `http://127.0.0.1:8765`. Для другого адреса задай `BOI_CATALOG_URL`, например в PowerShell:

```powershell
$env:BOI_CATALOG_URL = 'http://127.0.0.1:18765'
$env:BOI_BROWSER_CHANNEL = 'chrome'
npm test
```

`BOI_BROWSER_CHANNEL=chrome` позволяет использовать установленный Google Chrome вместо загруженного Chromium.
