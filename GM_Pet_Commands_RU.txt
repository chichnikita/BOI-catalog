GM-КОМАНДЫ ПИТОМЦЕВ — BOI ODIN
Русская памятка для BOI_Odin_4th_Anniversary_Win
Составлена: 24.10.2026

КАК ПОЛЬЗОВАТЬСЯ

Все команды вводятся в игровой чат отдельными сообщениями.
Сначала включи доступ командой:
  /setpower

Перед изменением питомца призови именно того питомца, которого хочешь настроить.
Для качества, роста, характера, усиления, поколения и навыков требование
призвать питомца прямо указано в исходном руководстве.

X и Y в шаблонах заменяются числами. Сами буквы вводить не нужно.
Команды set задают новое значение параметра, а не прибавляют его к текущему.
Примеры ниже — отдельные варианты действий, а не обязательный набор команд.

ОСНОВАНИЕ ПАМЯТКИ

Синтаксис и описание команд взяты из присланного тобой руководства.
ID Афины, яиц и диапазон её базового роста сверены с файлами этой сборки.
Выполнение команд на персонаже при подготовке памятки не проверялось.
Пределы из руководства другой версии отмечены отдельно.

==============================================================================
1. СОЗДАТЬ ПИТОМЦА — /addpet
==============================================================================

Формат:
  /addpet X 1 Y

X — ID вида питомца из Pet.slk.
Y — поколение питомца.
Средний параметр 1 оставляй как в приведённом руководстве:
его отдельное назначение в источнике не объяснено.

ID Афины в твоём сервере:
  3093  — физическая Афина.
  15143 — магическая Афина.

Примеры создания с поколением 1:
  /addpet 3093 1 1
  /addpet 15143 1 1

Выбери одну команду для нужного варианта.
В руководстве упоминаются поколения примерно до 200;
это не подтверждённый предел текущей сборки.

==============================================================================
2. ПОЛУЧИТЬ ЯЙЦО АФИНЫ — /additem
==============================================================================

Формат:
  /additem X Y

X — ID предмета.
Y — количество.

Физическая Афина, Fierce Athena Egg:
  /additem 62567 1

Магическая Афина, Mystic Athena Egg:
  /additem 62594 1

После выдачи используй яйцо из инвентаря. Нужен свободный слот питомца.
По локальным скриптам яйцо 62567 создаёт питомца 3093,
а яйцо 62594 — питомца 15143.

ID яйца и ID самого питомца различаются:
  /additem использует ID предмета.
  /addpet использует ID вида питомца.

==============================================================================
3. ИЗМЕНИТЬ КАЧЕСТВО — /setpetquality
==============================================================================

Формат:
  /setpetquality X

X — качество от 0 до 4 по руководству.
4 — Perfect, наивысшее качество в указанной шкале.

Пример:
  /setpetquality 4

Питомец должен быть призван.

==============================================================================
4. ИЗМЕНИТЬ ПОКАЗАТЕЛЬ РОСТА — /setpetgrowthrate
==============================================================================

Формат:
  /setpetgrowthrate X

X — итоговое значение роста.

Пример:
  /setpetgrowthrate 5000

Команда устанавливает рост 5000. Повторный ввод не прибавит ещё 5000.
Питомец должен быть призван.

У обеих Афин в текущем Pet.slk указан базовый диапазон роста 2500–3700.
Внешнее руководство называет максимум около 65500.
Предел GM-команды в твоей сборке отдельно не проверен.

==============================================================================
5. ИЗМЕНИТЬ ХАРАКТЕР — /setpetnature
==============================================================================

Формат:
  /setpetnature X

X — код характера от 0 до 7 по руководству.
В текущем PetNature.slk также присутствуют записи 0–7.

Значения, прямо названные в присланном руководстве:
  3 — Excited.
  5 — Calm.
  6 — Strength.
  7 — Forthright.

Название в русском клиенте может отличаться от английского.

Пример установки Calm:
  /setpetnature 5

Питомец должен быть призван.

==============================================================================
6. ИЗМЕНИТЬ УСИЛЕНИЕ (FORTIFICATION) — /setpetclever
==============================================================================

Формат:
  /setpetclever X

X — уровень усиления питомца.
В руководстве указан обычный максимум +15.

Пример:
  /setpetclever 15

Питомец должен быть призван.
Здесь описано Fortification; другие системы улучшения питомца
этой командой в руководстве не охватываются.

==============================================================================
7. ИЗМЕНИТЬ ПОКОЛЕНИЕ — /setpetgeneration
==============================================================================

Формат:
  /setpetgeneration X

X — новое поколение уже имеющегося питомца.

Пример установки поколения 2:
  /setpetgeneration 2

Питомец должен быть призван.
Точный допустимый диапазон этой команды для текущей сборки не проверен.

==============================================================================
8. ЗАМЕНИТЬ НАВЫК В ЯЧЕЙКЕ — /setpetskill
==============================================================================

Формат:
  /setpetskill X Y

X — номер ячейки навыка.
Y — ID нужного навыка питомца.

В присланном руководстве указан диапазон ячеек 0–8.
Нумерация и специальные ячейки в текущей сборке отдельно не проверены.
Команда меняет навык в указанной ячейке: прежний навык может быть заменён.
Питомец должен быть призван.

Шаблон для ячейки 0:
  /setpetskill 0 ID_НАВЫКА

Вместо ID_НАВЫКА подставь проверенный числовой ID.
Произвольный ID навыка в памятке не используется.

Для подбора навыка смотри:
  BOI_Odin_4th_Anniversary_Win\GameServer\Slk\Pet\PetSkill.slk
  BOI_Odin_4th_Anniversary_Win\GameServer\Slk\Skill\sSkillbase.slk

ID книги навыка из item.slk не следует подставлять вместо ID самого навыка.

==============================================================================
9. ИЗМЕНИТЬ ПОЛ — /setpetgender
==============================================================================

Формат:
  /setpetgender X

По руководству:
  0 — мужской пол.
  1 — женский пол.

Пример:
  /setpetgender 1

Для выбора нужного питомца предварительно призови его.
В строке этой команды источник отдельно не описывает выбор цели.

==============================================================================
10. ДОБАВИТЬ ОПЫТ — /addpetexp
==============================================================================

Формат:
  /addpetexp X

X — количество добавляемого опыта питомца.

Пример:
  /addpetexp 100000

Каждое выполнение добавляет указанное количество опыта.
Для выбора нужного питомца предварительно призови его.
В строке этой команды источник отдельно не описывает выбор цели.

==============================================================================
11. УСТАНОВИТЬ УРОВЕНЬ — /setpetlevel
==============================================================================

Формат:
  /setpetlevel X

X — итоговый уровень питомца.

Пример:
  /setpetlevel 70

Для выбора нужного питомца предварительно призови его.
В строке этой команды источник отдельно не описывает выбор цели.
Предельный уровень и ограничения относительно уровня персонажа
в присланном руководстве не объяснены.

==============================================================================
БЫСТРЫЙ ПРИМЕР: КАЧЕСТВО PERFECT И РОСТ 5000 ДЛЯ АФИНЫ
==============================================================================

Сначала призови Афину. Затем введи по очереди:
  /setpower
  /setpetquality 4
  /setpetgrowthrate 5000

Если дополнительно нужно усиление +15:
  /setpetclever 15

Если дополнительно нужен уровень 70:
  /setpetlevel 70

После каждой команды проверь соответствующий показатель в окне питомца.
